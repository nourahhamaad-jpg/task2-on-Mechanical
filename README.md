# Mechanical Task 2 - Custom Keychain Design

## Overview
In this task, a custom 3D model was designed using **Onshape**. The model features a geometric house-shaped keychain plate with an integrated circular hole for keyring insertion, created following precise dimensional constraints:
- **Circular Cut (Keyring Entry):** A cylindrical cut with a diameter of **4mm**.
- **Base Extrude:** Extruded to a thickness of **2mm**.
- **Output Format:** Exported as an `.stl` file ready for 3D printing.
